## 🎯 Overview

Sri Lanka Weather Tracker is a **feature-rich weather application** designed specifically for Sri Lankan locations. With coverage of **120+ cities, towns, and areas** across all 9 provinces, this application provides real-time weather tracking with advanced features including forecasting, data visualization, weather alerts, location comparison, and data export capabilities.

### Why This Application?

- ✅ **Comprehensive Coverage**: Every major location in Sri Lanka
- ✅ **Beautiful Design**: Modern glassmorphism UI with dynamic backgrounds
- ✅ **Advanced Features**: Forecasting, alerts, comparison, and export
- ✅ **No External Dependencies**: Self-contained weather simulation system
- ✅ **Easy Setup**: One-click installation with XAMPP
- ✅ **Responsive**: Perfect on desktop, tablet, and mobile devices

## 🚀 Installation

### Prerequisites

Before you begin, ensure you have:

- ✅ **XAMPP** (Version 7.4 or higher) with PHP and MySQL/MariaDB
- ✅ **Modern Web Browser** (Chrome, Firefox, Edge, or Safari)
- ✅ **Git** (optional, for cloning the repository)

### Step-by-Step Setup

#### 1️⃣ Download & Extract

**Option A: Clone with Git**
```bash
git clone https://github.com/reezmahanan/Weather-App.git
cd Weather-App
```

**Option B: Download ZIP**
- Download the repository as ZIP from GitHub
- Extract to your desired location

#### 2️⃣ Configure MySQL (Port 3307)

```plaintext
1. Open XAMPP Control Panel
2. Click "Config" next to MySQL → Select "my.ini"
3. Find the line: port = 3306
4. Change to: port = 3307
5. Save the file
6. Restart MySQL service in XAMPP
```

#### 3️⃣ Start XAMPP Services

```plaintext
- Start Apache Server
- Start MySQL (ensure it's running on port 3307)
- Verify both services show green status
```

#### 4️⃣ Deploy Application

```bash
# Copy all project files to XAMPP htdocs directory
# Windows: C:\xampp\htdocs\Weather-App\
# Mac: /Applications/XAMPP/htdocs/Weather-App/
# Linux: /opt/lampp/htdocs/Weather-App/
```

**Important:** Ensure the folder is named exactly `Weather-App`

#### 5️⃣ Access the Application

Open your web browser and navigate to:
```
http://localhost/Weather-App/
```

#### 6️⃣ Automatic Setup Complete! 🎉

On first run, the application will automatically:
- ✅ Create the `weather_app` database
- ✅ Create the `locations` table
- ✅ Populate with 120+ Sri Lankan locations
- ✅ Initialize realistic weather data
- ✅ Set up auto-update mechanisms

### Configuration (Optional)

If your MySQL uses different settings, update the database configuration:

**File:** `config/database.php` (or main PHP file)
```php
$host = 'localhost';
$port = '3307';  // Change if different
$dbname = 'weather_app';
$username = 'root';  // Change if different
$password = '';  // Add your password if set
```

### Verification

✅ **Check if setup was successful:**
1. Navigate to `http://localhost/Weather-App/`
2. You should see the main dashboard with locations dropdown
3. Select any location to view weather data
4. Try features like favorites, search, and alerts

## 📖 Usage Guide

### Basic Navigation

#### Viewing Weather for a Location
1. Open the application in your browser
2. Use the location dropdown or search bar
3. Select your desired location
4. View comprehensive weather details including:
   - Current temperature and conditions
   - Humidity levels
   - Wind speed and direction
   - Population and area statistics

#### Using Search Feature
- Type location name in the search box
- Results filter automatically as you type
- Click on any suggestion to view weather
- Press Enter to select the first result

### Advanced Features

#### 📊 5-Day Weather Forecast
1. Select any location
2. Click on the "5-Day Forecast" button/tab
3. View interactive temperature trends
4. Hover over chart points for detailed information
5. See min/max temperatures for each day

#### 🚨 Weather Alerts
- Alerts automatically display for extreme conditions:
  - **Red Alert**: Extreme heat (>35°C) or dangerous conditions
  - **Orange Alert**: High winds (>7 m/s) or humidity (>90%)
  - **Yellow Alert**: Moderate weather warnings
- Click alerts for detailed information and safety tips

#### ⭐ Managing Favorites
1. **Add to Favorites**: Click the star icon next to any location
2. **View Favorites**: Access from the favorites section
3. **Quick Access**: Click any favorite for instant weather
4. **Remove**: Click star again to remove from favorites

#### ⚖️ Comparing Locations
1. Click "Compare" button
2. Select multiple locations using checkboxes
3. View side-by-side comparison of:
   - Temperature differences
   - Humidity levels
   - Wind speeds
   - Weather conditions
4. Export comparison data if needed

#### 📤 Exporting Data
1. Click "Export" button
2. Choose format:
   - **CSV**: For spreadsheet applications
   - **PDF**: For professional reports
3. Select data to export:
   - Current location only
   - All locations
   - Comparison data
4. Download starts automatically

#### 🌐 Using Geolocation
1. Click the location icon/button
2. Allow browser location access when prompted
3. Application finds your nearest weather station
4. Weather data loads automatically

### Understanding Regional Patterns

#### 🌊 Coastal Areas (Western & Southern)
- **Characteristics**: Warm and humid
- **Examples**: Colombo, Galle, Negombo, Matara
- **Weather**: Consistent temperatures, high humidity
- **Best For**: Beach activities, water sports

#### 🏔️ Hill Country (Central Province)
- **Characteristics**: Cool and misty
- **Examples**: Kandy, Nuwara Eliya, Badulla, Ella
- **Weather**: Lower temperatures, frequent mist
- **Best For**: Mountain activities, tea plantation visits

#### 🌵 Dry Zone (North & North Central)
- **Characteristics**: Hot and arid
- **Examples**: Anuradhapura, Vavuniya, Trincomalee
- **Weather**: High temperatures, low humidity
- **Best For**: Cultural site visits (early morning/late evening)

### Tips for Best Experience

- 🔄 **Auto-Refresh**: Weather updates every 30 minutes automatically
- 📱 **Mobile Use**: Rotate device for better chart viewing
- 🌙 **Night Mode**: Browser dark mode compatible
- ⌨️ **Keyboard Shortcuts**:
  - `/` - Focus search bar
  - `Esc` - Close modals
  - Arrow keys - Navigate locations

## 🎨 Customization

### Changing Theme Colors

Edit CSS variables in `style.css`:

```css
:root {
  /* Primary Colors */
  --primary-blue: #4FC3F7;
  --primary-green: #4DB6AC;
  --primary-purple: #9C27B0;
  
  /* Glassmorphism Effects */
  --glass-bg: rgba(255, 255, 255, 0.1);
  --glass-border: rgba(255, 255, 255, 0.2);
  --glass-blur: 15px;
  
  /* Text Colors */
  --text-primary: #ffffff;
  --text-secondary: rgba(255, 255, 255, 0.8);
  
  /* Animations */
  --transition-speed: 0.3s;
  --animation-duration: 20s;
}
```

### Adding New Locations

**Method 1: Through Database**
```sql
INSERT INTO locations (name, province, temperature, humidity, wind_speed, conditions, population, area) 
VALUES ('New City', 'Western', 28.5, 75, 3.2, 'Partly Cloudy', 50000, 25.5);
```

**Method 2: Edit PHP Seeder**
Update the locations array in `index.php`:
```php
$locations = [
    // Add your new location
    ['name' => 'New City', 'province' => 'Western', 'temp' => 28, ...],
];
```

### Modifying Weather Simulation

Adjust weather patterns in the PHP simulation logic:
```php
// Temperature ranges
$tempMin = 20;  // Minimum temperature
$tempMax = 35;  // Maximum temperature

// Update frequency
$updateInterval = 1800; // Seconds (30 minutes)

// Regional modifiers
$coastalHumidity = 10;  // Added humidity for coastal areas
$hillCountryCooling = -5; // Temperature reduction for hills
```

### Customizing Alerts

Edit alert thresholds in `script.js`:
```javascript
const ALERT_THRESHOLDS = {
  extremeHeat: 35,      // °C
  coldWeather: 10,      // °C
  highHumidity: 90,     // %
  strongWind: 7,        // m/s
  storm: ['Thunderstorm', 'Heavy Rain']
};
```

### Changing Time Zone

Update clock display timezone:
```javascript
// In script.js
const timeZone = 'Asia/Colombo';  // Sri Lanka timezone
const timeFormat = {
  hour12: false,  // 24-hour format
  hour: '2-digit',
  minute: '2-digit',
  second: '2-digit'
};
```

### Database Configuration

Modify database settings:
```php
// Database connection

define('DB_NAME', 'weather_app');
define('DB_USER', 'root');
```

## 🐛 Troubleshooting

### Common Issues & Solutions

#### Application Not Loading
**Problem:** Blank page or error when accessing `http://localhost/Weather-App/`

**Solutions:**
- ✅ Verify Apache and MySQL are running in XAMPP
- ✅ Check if folder name is exactly `Weather-App` (case-sensitive)
- ✅ Ensure you're using correct URL with proper encoding
- ✅ Clear browser cache (Ctrl + Shift + Delete)
- ✅ Check browser console for errors (F12 → Console tab)

#### Database Connection Error
**Problem:** "Could not connect to database" or similar error

**Solutions:**
- ✅ Verify MySQL is running on port 3307
- ✅ Check database credentials in config file
- ✅ Ensure database user has proper permissions
- ✅ Try restarting MySQL service in XAMPP
- ✅ Check if firewall is blocking MySQL port

#### No Weather Data Showing
**Problem:** Locations load but no weather information displays

**Solutions:**
- ✅ Check if database was created automatically on first run
- ✅ Verify table `locations` exists and has data
- ✅ Clear browser cache and hard refresh (Ctrl + F5)
- ✅ Check PHP error logs in XAMPP
- ✅ Ensure JavaScript is enabled in browser

#### Favorites Not Saving
**Problem:** Favorite locations don't persist

**Solutions:**
- ✅ Enable cookies and local storage in browser settings
- ✅ Check if browser is in incognito/private mode (doesn't persist)
- ✅ Clear browser cache and try again
- ✅ Check browser console for storage errors
- ✅ Try a different browser

#### Charts Not Displaying
**Problem:** Weather forecast charts don't show

**Solutions:**
- ✅ Verify Chart.js library is loaded (check browser console)
- ✅ Check internet connection (if using CDN for Chart.js)
- ✅ Clear browser cache
- ✅ Ensure JavaScript is enabled
- ✅ Check for JavaScript errors in console (F12)

#### Geolocation Not Working
**Problem:** Location detection doesn't work or shows error

**Solutions:**
- ✅ Allow location permission in browser
- ✅ Use HTTPS (geolocation requires secure connection)
- ✅ Check if GPS is enabled on device
- ✅ Try a different browser
- ✅ Manually select location from dropdown

#### Slow Performance
**Problem:** Application loads slowly or lags

**Solutions:**
- ✅ Clear browser cache
- ✅ Check system resources (RAM, CPU usage)
- ✅ Reduce number of locations in comparison
- ✅ Close unnecessary browser tabs
- ✅ Optimize database queries (add indexes)
- ✅ Use a more powerful local server

#### Export Functions Not Working
**Problem:** CSV/PDF export fails or downloads corrupt file

**Solutions:**
- ✅ Check browser download settings
- ✅ Ensure popup blocker isn't blocking downloads
- ✅ Verify file permissions in download folder
- ✅ Try different export format
- ✅ Check PHP memory limits in php.ini

### Getting Help

If you're still experiencing issues:

1. **Check Browser Console**: Press F12 → Console tab for error messages
2. **Check PHP Errors**: Look at XAMPP error logs
3. **GitHub Issues**: [Open an issue](https://github.com/reezmahanan/Weather-App/issues) with:
   - Detailed problem description
   - Steps to reproduce
   - Browser and OS information
   - Error messages or screenshots
4. **Community Support**: Check existing issues for similar problems

Enable debug mode for detailed error information:
```php
// Add to top of index.php

ini_set('display_errors', 1);
```

**Remember to disable in production!**
